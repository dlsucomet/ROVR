# Pilot feedback

**Only for the pilot** (PP1–PP4). Each pilot participant does both conditions on two different days.
- **Part A** (participant): at the end of **each** pilot day, after the interview. About 5 minutes.
- **Part B** (participant): at the end of the **second** day only. About 3 minutes.
- **Part C** (researchers): fill in for every pilot session. It records what the pilot must confirm before the user study.

---

## Part A: the session (participant, each day)

**Participant code:** ______ **Day:** ○ 1 ○ 2 **Condition today:** ○ ROVR (voice) ○ Manual (controller)

We're testing the study itself, not you. Please be critical: anything confusing or too long helps us fix it before the real study.

1. **The instructions before you started were clear.**
   *(1 Strongly disagree – 5 Strongly agree)*
2. **The practice area gave me enough time to learn how to move.**
   *(1–5)*
3. **In each world, I knew what I was supposed to do.**
   *(Grid: rows Plain / Maze / House, columns 1–5)*
4. **Was any task unclear or impossible to finish? Which, and why?** *(paragraph)*
5. **Were any questionnaire questions confusing or hard to answer? Which ones?**
   *(Checkboxes: sickness symptoms (SSQ) / workload scales (NASA-TLX) / usability statements (SUS) / word pairs (UEQ-S) / None)*
   - What was confusing? *(paragraph)*
6. **The questionnaires after each world were…**
   *(Too short / About right / A bit long / Far too long)*
7. **The whole session was…**
   *(Too short / About right / A bit long / Far too long)*
8. **The breaks between worlds were long enough.**
   *(1–5)*
9. **How comfortable was the setup?**
   *(Grid: rows headset fit / swivel chair / controller (Manual) / microphone and speaking (ROVR), columns 1 Very uncomfortable – 5 Very comfortable, plus "Didn't use")*
10. **Did anything go wrong technically** (freezing, not hearing you, moving the wrong way, the controller not responding)? *(paragraph)*
11. **Anything else we should change before the real study?** *(paragraph)*

## Part B: comparing the two conditions (participant, day 2 only)

12. **Overall, which way of moving did you prefer?**
    *(Voice (ROVR) / Controller / No preference)*
    - Why? *(paragraph)*
13. **Which was easier in each world?**
    *(Grid: rows Plain / Maze / House, columns Voice / Controller / Same)*
14. **Which was more tiring to use?**
    *(Voice / Controller / Same)*
15. **Did doing the first condition change how you approached the second?** For example, you remembered the maze, or used the same strategy. *(paragraph)*
16. **If you could combine the two, how would you want it to work?** *(paragraph)*

Question 15 matters: each pilot participant sees the same worlds twice, so the second day's times are expected to be faster. Pilot task times are for checking the setup, not for comparing the conditions.
